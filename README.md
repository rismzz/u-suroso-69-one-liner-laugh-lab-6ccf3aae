A deterministic program that writes one short funny line to `/output/entry.txt` answering the prompt — the excuse a robot vacuum gives after eating a sock: it didn't eat the sock, it adopted it, and the sock now pays rent in dust bunnies under the couch. No network, no randomness, no model call: the same 97 characters on every run.

## Run it

```sh
python3 main.py
```
